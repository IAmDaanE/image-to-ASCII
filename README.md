# Image to ASCII

Turn any png image into an array of characters that looks just like it. Perfect for TUI apps.

## Getting Started

### Running the Program

**Requires:** Python 3.9 - 3.14
1. Install the required libraries, preferably in a venv.

    ```
    pip install -r requirements.txt
    ```
2. Run the program.

    ```
    python src/main.py
    ```

### Usage

Run the program with the command shown above and replace the string with the file path to your image. You might need to zoom out the terminal to properly see the image by pressing ctrl - repeatedly.
